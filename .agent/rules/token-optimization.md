# Token & Context Optimization Rules

- **Grep только по сигнатурам:** в `Select-String` / `grep_search` искать только `^(local )?function ` или точные имена событий/типов. Не включать в регулярку общие слова (`Attribute`, `State`, `Position`, `Death`).
- **Сжатый Handoff в `exit_plan_mode`:** не пересказывать требования пользователя — указывать только `Файл:StartLine-EndLine -> что изменить` (лимит до 1500 слов).
- **Без повторного чтения:** после выхода из Plan Mode не перечитывать файлы/диапазоны, уже разобранные в плане, если они не менялись.
